## Blunt verdict
**Already done; do not claim as novel:**
1. That NetFlow-based NIDS collapse cross-dataset, including leave-one-out on all four NF-v3 sets (P01, P02; also P05, P21, P10, P14 and others).
2. That shortcut features exist in these datasets: ports (P06, P20, P22), TTL (P02 calls it "documented"), and probe-level audits of NF-v3 (P04).
3. That domains are trivially separable from raw NetFlow features (P02: AUC ≥ 0.996).
4. That DANN/CORAL baselines are needed, and that source thresholds fail on new networks (P05, P06, P46, P47).
5. That random splits inflate results (many CIC-based papers).

**Direct answer to the key question:** yes. Someone (Gazi et al., P01) has already run leave-one-testbed-out on all four NF-v3 datasets, with source-only tuning and 18 methods. Code went public on 2026-11-12; the paper text was not found. Rayamajhi (P02) covers all four v3 sets pairwise and points to TTL as a known artifact. We found **no evidence that anyone has published a mechanistic, per-feature-group attribution of *benign* environment-signature shift to LODO loss on all four V3 sets with controlled ablations.** We cannot rule it out, because P01, P03 and P04 are visible to us only through code-deposit descriptions.

**Angles that still look open (in order of how defensible they are):**
- (a) **Quantitative attribution of LODO loss to feature groups**, measured by each group's benign-vs-benign shift between networks (for example a benign-only domain-classifier AUC or a Wasserstein distance per feature), using group-wise ablations and "transplant" tests (swap only one group's benign distribution). It must be tested whether the loss is driven by *benign* shift or by attack-tooling shift. Prior work separates domains, but separability alone is not attribution, and P02 shows separability survives heavy feature removal. That result is a warning: removal may not recover performance.
- (b) **A negative or conditional result on remedies.** Prior removal attempts mostly failed (P02, P05) or gave small gains (P20). A careful, pre-registered test of benign-relative per-environment normalization against removal, CORAL and DANN, under LODO with source-only thresholds, is publishable either way. We must handle P02's warning about per-domain scaling and state clearly that the method uses unlabeled target benign statistics, which makes it transductive.
- (c) **Random vs chronological gap on all four V3 sets.** This is a low-novelty addition and should be an evaluation lens, not a contribution.

**Required before writing:** get the full texts of P01, P02 and P04 (and Layeghy & Portmann 2023 and Sarhan et al. 2022 BDR, whose abstracts we could not retrieve). Check whether any of them already does (a). If P01 or P04 contains a feature-attribution analysis, the contribution must narrow to (b).
