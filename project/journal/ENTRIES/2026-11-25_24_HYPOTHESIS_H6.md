# HYPOTHESIS H6 — 2026-11-25 — written after the prior-art check (literature/prior_art_v2/h6_minimax.md), BEFORE any DEV run
Lesson from H5: I cannot find the training anomalies without labels. H6 does not try. It uses one structural fact: a shielding anomaly cluster is SMALL compared with the normal mass, so a test point inside it is close to its neighbours but must cross a large gap to reach the bulk of the data.
Method MINIMAX-CORE (src/ad/methods_t2.py::MinimaxCore): build the Euclidean MST of the training set; run Kruskal until one component holds ≥ frac·n points (the "core"); m_j = minimax path distance from training point j to the core; score(x) = min_j max(d(x,j), m_j). This is the single-linkage height at which x joins the majority component.
Predictions (DEV 23 datasets, seeds 0–2, both regimes):
P1. CONTAMINATED mean AUROC ≥ 83 (kNN5 72.83). CLEAN mean AUROC ≥ 85.6 (kNN5 86.13 − 0.5). This is the same bar as H5.
P2. Beats GLOSH and CBLOF in the contaminated regime (paired Wilcoxon over datasets, p < 0.05).
Risk I expect: multimodal normal data (several normal clusters, none ≥ 50 %) gets false alarms, and a single noisy bridge point can merge an anomaly cluster into the core.
Pre-registered variants (all counted): H6a frac=0.5; H6b frac=0.5 + any component ≥ 5 % of n joins the core; H6c frac=0.3. Baselines added: knn1, CBLOF, COF, GLOSH (hdbscan, min_cluster_size=5, min_samples=5). Selection among H6a–c uses DEV only; HOLDOUT and seeds 100–104 are reserved for the frozen choice.
