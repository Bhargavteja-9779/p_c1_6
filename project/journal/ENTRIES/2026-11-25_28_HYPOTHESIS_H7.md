Ladder 6.4 step 5 (change angle). H5 tried to clean the training set globally (circular); H6 assumed one normal core (wrong:
normals are multi-modal, anomalies chain to them). H7 makes no global decision at all. A shielding group is a set of training
points that are each other's MUTUAL nearest neighbours and that is small. For a test point I remove only the small groups that
its own nearest training neighbours belong to, and then measure its kNN distance to what is left. A test anomaly sitting inside
a shielding group loses its shield; a normal point in a large normal mode loses nothing (large components are never removed).
Method LOCO-kNN (src/ad/methods_t2.py::LocoKNN): mutual-kNN graph with k_m on the training set; connected components of size
≤ cap·n are "small"; score(x) = 5th-NN distance from x to training \ (small components containing any of x's 5 NN).
Toy check only (planted 15-point anomaly cluster, not a result): kNN5 AUROC 0.00, LOCO 1.00; but 11 % of Gaussian training normals
