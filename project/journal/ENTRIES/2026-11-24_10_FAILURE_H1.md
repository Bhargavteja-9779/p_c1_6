# FAILURE — 2026-11-24 — H1 is not supported
I expected removing or re-expressing "environment-signature" features to recover cross-network performance. It did not.
- ESF (drop env-discriminative features), τ ∈ {0.3, 0.4, 0.5}: 0.5939 / 0.5806 / 0.5978 vs XGBoost 0.6114; paired differences −0.014 to −0.031, Holm p = 0.55–1.0. No gain.
- PEN (per-network benign quantile normalisation): 0.4337, i.e. −0.178 vs XGBoost. Every PEN variant is the worst tree-based arm.
- Group ablations: dropping TTL (0.5983), app fields (0.6125), flags (0.6118), port/proto (0.5940) change little; dropping TCP window hurts the mean (0.5264; UNSW 0.6174 → 0.4004) but helps BOT (0.0921 → 0.4336).
My best explanation: the loss is not mainly caused by benign-traffic covariate shift in a few feature groups. Evidence: the diagnostics in entry 11.
This agrees with prior work that feature removal does not restore transfer (Rayamajhi 2026 abstract; Priyanga 2026 abstract) and Rayamajhi's warning about per-domain scaling.
